# CAD-Harness 0.10.0b1

First packaged beta of the source-backed CAD framework and local Studio.
Experimental interfaces and schemas may change. Licensed under Apache-2.0,
Copyright 2026 Jason Shaw; bundled dependencies retain their own licenses.

## Downloads and installation

Use `cad_harness-0.10.0b1-py3-none-any.whl` for installation. The `.tar.gz` is
the complete Python source distribution, including editable frontend inputs,
tests, guides and prebuilt Studio assets. Neither contains Python or native
dependencies. GitHub's automatic repository source ZIP is not the built wheel.
Download the assets from this release and verify them against `SHA256SUMS`.

Windows PowerShell, from the download directory:

```powershell
Get-FileHash .\cad_harness-0.10.0b1-py3-none-any.whl -Algorithm SHA256
python -m venv .cad-venv
.\.cad-venv\Scripts\python.exe -m pip install ".\cad_harness-0.10.0b1-py3-none-any.whl[mcp,studio]"
.\.cad-venv\Scripts\python.exe -m pip check
.\.cad-venv\Scripts\python.exe -m cadharness demo
```

On Linux/macOS, verify with `sha256sum -c SHA256SUMS` (macOS:
`shasum -a 256 -c SHA256SUMS`), create the environment with `python3`, and
use `./.cad-venv/bin/python`. Runtime needs no Node/npm. Pip needs access to
the separately installed dependencies. No PyPI publication is part of this beta.

## Included behavior

- Editable build123d projects with geometry-derived checks and explicit
  pass/fail/indeterminate evidence; verified STEP/STL export rejects stale evidence.
- Local Studio with retained briefs, source, revisions, measurements, comparison,
  component isolation and downloads; stdio MCP tools for IDE assistants.
- `demo` builds a real three-hole failure and four-hole repair against one
  frozen brief. Inspect retained evidence and explicitly export the passing part.
- MCP setup previews for Codex and Claude Desktop, additive application with
  backups, and optional real stdio preflight. Explicit trusted roots are required.

## Compatibility and limits

The release gate runs Python/CLI/MCP tests on CPython 3.11–3.14 across Windows,
Linux and macOS. Full clean installation, package lifecycle and wheel/sdist
checks run on Python 3.12 on those runners. Real Playwriter rendering and demo
acceptance run on Linux, Python 3.12. Use the attached `BUILD.json` to locate
the exact commit and CI run; require all jobs to pass before publication.
`DEPENDENCIES.json` records the Linux candidate's installed versions/notices,
not a cross-platform lock or a guarantee about future dependency resolution.

Physical fit, strength and manufacturing performance require separate validation.
Historical-version/kernel migrations, Claude Desktop interactive tool discovery,
native touch hardware, free-threaded Python, 32-bit Python and Windows ARM
remain unverified. Project factories execute trusted local Python without
sandboxing. Studio uses no nested model calls; assistant access is separate.

Existing users should stop owning MCP/Studio processes, back up source and
workspace history, then install the wheel using their existing interpreter.
Retained evidence may require a new revision after evaluator/kernel changes.
Earlier installations named `cadharness` require the documented name migration.
